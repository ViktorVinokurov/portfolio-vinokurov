# Архитектура портфолио

Одностраничный лендинг (SPA) без бэкенда. После `npm run build` получается статический каталог `dist/`, который можно разместить на любом статическом хостинге (GitHub Pages, Vercel, Netlify, nginx).

## Общая схема

```
index.html (class="dark", lang="ru")
  └─ src/main.tsx ── <Provider store>
       └─ App.tsx
            ├─ CursorGlow        свечение за курсором
            ├─ Header            шапка: навигация с подсветкой активного раздела, прогресс скролла
            └─ main
                 ├─ Hero         имя, роль, фото, стаж (считается от дат в profile)
                 ├─ About        текст «обо мне», факты, личные качества
                 ├─ Skills       группы навыков
                 ├─ Experience   таймлайн мест работы и проектов
                 ├─ Projects     репозитории из GitHub API + фильтр по языку  ← Redux
                 ├─ Education    вуз и курсы
                 └─ Contacts     ссылки для связи
```

Все секции, кроме `Projects`, статические: они только отображают данные из `src/data/profile.ts`.

## Структура каталогов

| Путь | Назначение |
|---|---|
| `src/data/profile.ts` | Весь текстовый контент: профиль, контакты, навыки, опыт, образование. Единственное место, где хранится логин GitHub |
| `src/store/` | Redux: `index.ts` (store и типизированные хуки), `githubApi.ts` (RTK Query), `projectsSlice.ts` (UI-состояние фильтра) |
| `src/components/sections/` | Секции страницы, по одной на файл |
| `src/components/ui/` | Компоненты shadcn/ui, сгенерированные CLI. Правятся вручную только при необходимости, обновляются через `npx shadcn add <name> --overwrite` |
| `src/components/Section.tsx` | Общий каркас секции: якорь, номер, отступы, анимированный заголовок |
| `src/components/*.tsx` | Анимационные компоненты (`Reveal`, `SplitText`, `TiltCard` и др.), см. раздел «Анимации» |
| `src/lib/format.ts` | Склонение числительных, подсчёт стажа, форматирование дат |
| `src/assets/photo.jpg` | Фото (копия `docs/img/portfolio_temnyi.jpg`), импортируется через Vite и получает хэш в имени |

## Поток данных

### Контент профиля

`profile.ts` → импорт в секции → рендер. Чтобы изменить текст, опыт или навыки, достаточно отредактировать этот файл, компоненты трогать не нужно.

Стаж в Hero (`лет в веб-разработке`) вычисляется из `profile.webDevStart` при загрузке страницы, поэтому цифра не устаревает. Число компаний берётся из длины массива `experience`.

### Репозитории GitHub

```
Projects
  └─ useGetReposQuery(profile.github.username)
        └─ githubApi (RTK Query)
              GET https://api.github.com/users/{username}/repos?per_page=100&sort=pushed
              transformResponse: убрать форки и репозитории из profile.github.hiddenRepos
        └─ кэш в store.githubApi (дедупликация запросов, повторное использование)
  └─ useAppSelector(state.projects.language) → фильтрация на клиенте
  └─ dispatch(setLanguage(lang)) ← кнопки фильтра
```

Состояния секции: загрузка (скелетоны shadcn), ошибка (сообщение со ссылкой на профиль GitHub), данные (сетка карточек).

Ограничения:
- Запросы без авторизации: лимит 60 запросов в час с одного IP. Токен в клиентский бандл добавлять нельзя, он станет публичным.
- Если лимита перестанет хватать, запрос стоит перенести на этап сборки (скрипт, который сохраняет JSON в `public/` перед `vite build`), а `githubApi` переключить на чтение этого файла. UI менять не придётся.

## Стили и тема

- Tailwind CSS v4 подключён через плагин `@tailwindcss/vite`. Отдельного `tailwind.config` нет, вся настройка лежит в `src/index.css`.
- Цвета задаются CSS-переменными shadcn (`--background`, `--primary`, …) в формате OKLCH. Сайт всегда тёмный: на `<html>` стоит класс `dark`, а пурпурная палитра определена в блоке `.dark`. Блок `:root` остался от генерации shadcn и не используется.
- Основной акцент — `--primary: oklch(0.66 0.24 305)` (пурпурный). Декоративные градиенты дополнительно используют `fuchsia-*` и `violet-*` из палитры Tailwind.

## Анимации

Анимации, завязанные на скролл, курсор и состояние, сделаны на библиотеке `motion` (`motion/react`). Бесконечные декоративные циклы сделаны на CSS-keyframes в `index.css`. Общая кривая `easeOutExpo` лежит в `src/lib/motion.ts`.

Переиспользуемые компоненты (`src/components/`):

| Компонент | Что делает |
|---|---|
| `Reveal` | Появление блока при попадании в экран (`whileInView`): прозрачность, размытие, сдвиг. Проп `from` задаёт направление (`bottom`/`left`/`right`/`scale`), `delay` даёт каскад в мс |
| `SplitText` | Текст выезжает из-под маски по словам или буквам с каскадом (`delayChildren: stagger()`). Используется в заголовках секций и в имени в Hero |
| `ScrollHighlight` | Слова абзаца загораются по мере прокрутки: прозрачность каждого слова привязана к `scrollYProgress` |
| `TiltCard` | 3D-наклон за курсором и световое пятно под ним на пружинах (`useSpring`). Работает только с мышью |
| `CountUp` | Число набегает от 0 при появлении на экране (`animate`) |
| `Marquee` | Бесконечная бегущая строка из двух копий ленты (CSS `animate-marquee`), пауза при наведении |
| `CursorGlow` | Пурпурное свечение, которое с запаздыванием следует за курсором по всей странице |

Эффекты по секциям:

| Где | Эффект |
|---|---|
| Header | Прячется при прокрутке вниз и возвращается при прокрутке вверх. Подложка активного раздела перетекает между пунктами (`layoutId`). Прогресс-бар прокрутки на пружине |
| Hero | Имя по буквам, переливающийся градиент фамилии, сменяющиеся технологии (`AnimatePresence`), фото с 3D-наклоном, парящие бейджи. При уходе вверх параллакс: текст гаснет, фото отстаёт и уменьшается |
| Section | Большой контурный номер секции движется медленнее контента (параллакс) |
| About | Первый абзац подсвечивается по мере прокрутки, факты выезжают справа, карточки качеств с наклоном |
| Skills | Две бегущие строки навыков навстречу друг другу, бейджи в карточках выпрыгивают по очереди |
| Experience | Линия таймлайна прорисовывается вслед за прокруткой, точки появляются с пружиной, карточки проектов выезжают с разных сторон |
| Projects | При смене фильтра карточки переезжают на новые места (`layout` + `AnimatePresence`), подложка фильтра перетекает (`layoutId`) |
| Contacts | Вращающаяся градиентная рамка (conic-gradient), каскадное появление ссылок |

Доступность: `MotionConfig reducedMotion="user"` в `App.tsx` отключает перемещения при `prefers-reduced-motion`. CSS-анимации отключаются вариантами `motion-reduce:`.

## Как расширять

- **Новая секция:** создать компонент в `src/components/sections/`, обернуть в `Section` (якорь, заголовок), контент вынести в `profile.ts`, добавить в `App.tsx` и при необходимости в `navItems` в `Header.tsx`.
- **Новый компонент shadcn:** `npx shadcn@latest add <name>`.
- **Новое глобальное состояние:** отдельный slice в `src/store/`, подключить в `configureStore`. Серверные данные описывать эндпоинтами RTK Query, а не через `createAsyncThunk`.
